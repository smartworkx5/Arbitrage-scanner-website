CRYPTO ARBITRAGE MATRIX - MARKETING WEBSITE
===========================================
Static HTML/CSS/JS. No build step.

1. Set your domain:   sh replace-domain.sh https://your-domain.com
2. Deploy: drag the folder to Vercel, Netlify or Cloudflare Pages.
3. Contact form: swap the mailto action in /contact/index.html for Formspree or Netlify Forms.
4. Search Console: add the domain, verify, submit https://your-domain.com/sitemap.xml
5. Review /privacy/ and /terms/ (templates) with a professional before launch.

Every 'Launch app' button opens: https://cryptoscanner-indol.vercel.app/
